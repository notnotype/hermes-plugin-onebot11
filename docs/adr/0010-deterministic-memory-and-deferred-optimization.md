# ADR-0010：确定性记忆候选与 RAG/自优化延期

- 状态：已接受
- 日期：2026-08-08

## 决策

本轮的“记忆检测”只使用确定性回指词（例如“之前、上次、刚才、继续”）以及当前群已有的 SQLite 摘要/最近原文。它只决定是否进入低价 selector，不声称已经接入 RAG。

不在运行时让 Hermes 自动修改 Python、权限、白名单、关键词或触发脚本。未来如果实现自优化，只生成配置 diff 和理由，由超级管理员审核后部署。

## 原因

向量库、RAG 评估和自动修改权限都需要新的存储、权限和回滚闭环；当前主要风险仍是队列可靠性、身份隔离和旁路调用成本。确定性候选已经覆盖常见连续对话场景，复杂度和收益更平衡。

## 影响

- 当前“记忆检测”不能理解同义表达，也不会主动检索外部知识。
- 触发质量通过人工标注或离线回放评估，不虚构运行时漏唤醒统计。
- 未来接入 RAG 或自优化必须另建任务，明确索引、预算、审核、回滚和权限合同。
