# v0.1.0（2026-08-04）

首个可用版本：OneBot 11 接入最小闭环（私聊+群聊、消息查询工具、权限管理）。

## 功能

- 插件骨架：repo 根即插件目录,`hermes plugins install notnotype/hermes-plugin-onebot11` 可直接安装
- 反向 WS 服务端（Bearer 鉴权）,兼容 LLBot / NapCat 等 OneBot 11 框架 ws-reverse
- HTTP 发送与动作调用（重试、长文本分块、reply 段、图片下载）
- 三个平台工具：qq_get_message / qq_get_group_msg_history / qq_get_friend_msg_history（toolset: onebot11）
- 权限：群白名单（ONEBOT11_ALLOWED_GROUPS）、群聊 @ 触发（ONEBOT11_REQUIRE_MENTION）、
  私聊策略（ONEBOT11_DM_POLICY）、管理员列表（ONEBOT11_ADMINS）、会话范围校验（群聊只能查本群/私聊只能查自己）

## 已验证

- 单元测试：协议层 49 passed + adapter 层 19 passed（CI lint-test 通过）
- 与 LLBot 8.1.5（直连模式）真实联调:反向 WS 连接、事件上报、群白名单过滤、@ 触发均验证

## 配置速览

| env | 默认 | 说明 |
|---|---|---|
| ONEBOT11_HTTP_API | 必填 | LLBot ob11 HTTP 地址（如 http://127.0.0.1:3000） |
| ONEBOT11_SELF_ID | 必填 | 机器人 QQ 号 |
| ONEBOT11_ALLOWED_GROUPS | 空 | 群白名单（逗号分隔;空 = 所有群） |
| ONEBOT11_REQUIRE_MENTION | true | 群聊必须 @ 机器人才响应 |
| ONEBOT11_DM_POLICY | open | 私聊策略 open/allowlist/disabled |
| ONEBOT11_ADMINS | 空 | 管理员 QQ 列表（空 = 开放模式） |
| ONEBOT11_WS_PORT | 18880 | 反向 WS 监听端口 |
| ONEBOT11_ACCESS_TOKEN | 空 | 可选,与框架配置的 Authorization 一致 |
