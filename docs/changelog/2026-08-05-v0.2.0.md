# v0.2.0（2026-08-05）

OneBot 11 从最小消息闭环升级为共享群 session、持久队列和安全出站合同。

## 主要变化

- 群固定一个 shared session；所有允许的群消息先进入 SQLite WAL 队列。
- 增加 @、关键词、always 和显式旁路 auxiliary LLM trigger；未触发消息不会丢失。
- 增加 lease、heartbeat、崩溃恢复、消息去重、摘要、tombstone 和 `uncertain` 人工 resolve。
- 普通用户默认只能使用当前目标范围内的只读工具；超级管理员才能使用群管理写工具。
- 写工具改为预览 + `/onebot confirm TOKEN`，确认命令不进入 Hermes session。
- 查询动作可有限重试；OneBot 非幂等发送和群管理动作不自动重试，未知结果不会自动重放 Agent turn。
- 反向 WS 增加有界队列、同 chat 顺序、全局 inflight 和失败断开恢复；媒体下载增加 SSRF、类型和总大小限制。

## 验证范围

本地协议、队列、权限、WS、HTTP 和 Hermes adapter 测试已覆盖；真实 LLBot/NapCat 的本轮 shared session、重启恢复、确认写操作和 unknown 联调仍需单独完成。
