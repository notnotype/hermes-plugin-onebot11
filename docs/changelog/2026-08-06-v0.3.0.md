# v0.3.0（2026-08-06）

OneBot 11 收口 lease fencing、非幂等出站和分层触发，进入可联调的生产实现。

## 主要变化

- 增加 lease 阶段和 `outbound_started` fencing；过期 lease 按阶段恢复，未知出站进入 `uncertain`，不自动重放。
- 明确已知失败的 2/4/8 秒退避和最多 3 次自动尝试；`failed` 与 `uncertain` 只能由管理员 resolve。
- 收口入队前授权、shared group session、精确 `(session_id, turn_id)` 身份绑定、目标类型和历史作用域校验。
- 将 Task 3 balanced spike 落入生产代码：问句/记忆候选、5 秒 debounce、`trigger|wait|ignore` 三态、60 秒活跃窗口和 3 次仲裁上限。
- LLM trigger 固定使用显式旁路模型、`fallback_policy=none`、`max_attempts=1`；旧 Hermes auxiliary API 不支持时安全跳过。
- 增加 `clear` 对旧触发状态的失效处理、退避期间恢复抑制、👀 reaction best-effort 生命周期和媒体安全边界。

## 验证范围

本地协议/状态机、Hermes 组合环境和临时 `HERMES_HOME` 注册 smoke 已覆盖；真实 LLBot/NapCat 验收结果以 `PROJECT-STATUS.md` 为准。
