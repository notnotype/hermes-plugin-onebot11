# v0.3.0（2026-08-06）

OneBot 11 上下文与角色权限在可靠性边界上完成收口。

## 主要变化

- 入站、cron 和恢复路径共用同一份群/私聊白名单策略；未知策略、缺 adapter、权限检查异常和审计写异常均 fail-closed。
- cooldown 最近触发时间持久化到 SQLite；到期后自动恢复标记为触发候选的 pending 消息。LLM 判断期间新增消息会重新安排判断。
- reaction 清理状态持久化；重启和恢复只有限重试 `unset`，不重放 `set`、Agent turn 或群管理动作。
- adapter 关闭时 fencing 活动 lease；旧 Hermes straggler 不再访问已关闭 SQLite 或继续调用 OneBot 出站。
- `delegate_task` 从 OneBot 角色配置和运行路径中禁用；等待 Hermes 上游 per-turn 工具策略。
- 非 URL 图片通过 OneBot `get_image` 解析；本地文件只允许从显式 `media_source_roots` 复制，并继续执行大小、类型和魔数校验。
- 纯媒体/空文本消息不再在 slash 命令解析阶段崩溃；`file` 与 `url` 字段分别保存。
