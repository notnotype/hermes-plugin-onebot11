# v0.3.0 - OneBot 11 上下文物化与细粒度权限

- 当前群 queue batch 由确定性早期摘要和最近原文组成一个 synthetic user turn；ack 不再追加跨轮 SQLite 摘要。
- 新增 `user`、`trusted_user`、`super_admin` 三角色和精确工具名配置。
- 新增 `onebot_get_permissions`、`onebot_set_role_tools`、`onebot_set_trusted_users`，配置写入需要 `/onebot confirm`。
- 权限门禁覆盖未知 `onebot_*` 名称、跨平台/子代理 handler 调用和 trusted 用户 metadata 恢复；配置读改写增加同进程串行保护。
- 群消息支持 `/context`、`/status`、`/whoami`、`/help`、`/commands` 旁路命令，并拒绝危险 session slash command。
- `/status` 只返回队列/lease 运维字段，补齐当前 `chat_type`，不再把旧兼容 summary 原文发送到群里。
- 保留 Hermes `pre_provider_request` 和 per-turn tool policy 的上游接口边界；当前版本不通过 `pre_llm_call` 伪装动态上下文。
