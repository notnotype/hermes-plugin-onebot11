# v0.3.1（2026-08-06）

OneBot 11 收口同实例 reconnect、配置合同和非幂等管理动作恢复路径。

## 主要变化

- 修复干净环境 `pip install -e ".[dev]"` 的 setuptools 包发现失败，明确只打包 `adapter` 和 `onebot11*`。
- adapter disconnect 后可 reopen 同一路径 SQLite 和 dispatcher；未出站 lease 回 pending，已出站 lease 进入 uncertain，内存 active/engaged 状态回到 idle。
- 抽出统一运行时配置解析器，`validate_config()` 与 adapter 构造共同校验数值边界、有限浮点、地址、角色、媒体、队列和 WS 配置。
- 在队列 SQLite 增加管理动作 operation ledger；进程恢复不会遗忘 unknown，`resolve action retry|discard` 不会直接重放动作。
- 补全 LLM trigger 审计的 pending、输入字节、真实耗时和并发等待字段，不再把 semaphore 等待称为 rate limited。
- 增加可复现的本地 Hermes 集成脚本和 reconnect/operation/config 回归测试。

## 验证范围

纯插件门禁、Hermes 组合测试和 strict auxiliary 测试结果记录在 `PROJECT-STATUS.md`；真实 LLBot/NapCat 行为不由 CI 代替。
