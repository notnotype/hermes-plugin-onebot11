# v0.4.0（2026-08-08）

- 群共享 session 改为 TurnAnchor：每个真实触发消息拥有固定 batch、authority、reaction 和 reply 边界，同群按序单 lease follow-up。
- selector 使用显式 message key；目标消息消失时不静默 retarget，硬触发和 recovery 保留真实 anchor。
- 新增 `trusted_user` 角色；只能使用明确配置的只读工具，不能修改权限、白名单或角色。
- 保留 SQLite lease fencing、reconnect reset、operation ledger、unknown 人工 resolve 和 `👀` best-effort reaction。
- 旁路 LLM 继续固定 `fallback_policy=none`、`max_attempts=1`；旧 Hermes API 安全禁用，不回退主 Agent。
- 本版本不包含 RAG、向量库、运行时自优化、queued `⏳` reaction、OneBot 12 或 exactly-once 非幂等出站。
