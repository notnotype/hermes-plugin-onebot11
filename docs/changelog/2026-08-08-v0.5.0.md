OneBot 11 出站图片与可靠性收口。

- 修复真实 v7/v8 SQLite 表结构迁移顺序和迁移失败后的连接清理。

- `error_kind="unknown"` 不再触发 Hermes retry、plain-text fallback 或 cron live-to-standalone fallback。
- 增加本地 Hermes 媒体/unknown 组合验收和出站图片 ADR。
