# v0.6.0（2026-08-09）

- LLM Trigger 改为插件自有 `@earendil-works/pi-ai@0.83.0` Node helper，
  不再依赖 Hermes auxiliary、strict fallback 参数或 Hermes 主 Agent fallback。
- 增加 `llm_trigger.base_url` 和 `llm_trigger.api_key_env`，自定义 provider
  只允许 HTTP/HTTPS OpenAI-compatible endpoint，密钥只从环境变量读取。
- 删除 Hermes auxiliary 注册、能力探测和旧 Hermes 媒体结果能力门禁。
- Agent 最终回复图片保持受限 `base64://` best-effort；`send_message`/cron
  图片仍不承诺通用媒体合同。
- 新增 Node/npm 安装与 Hermes 组合 smoke 合同，版本从 0.5.0 升级到 0.6.0。
