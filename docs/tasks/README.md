# Task Walkthrough 规则

- 每个重大任务一个目录：`docs/tasks/<序号>-<task-slug>/README.md`。
- 记录：用户需求、目标、执行过程、关键决策、变更文件、验证结果、后续 TODO。
- 同一功能后续调节,继续更新原任务目录,不每轮新建碎片文档。
- 任务完成后的 walkthrough 要报告**实际结果与任务计划的出入**。
- 归档任务移到 `docs/tasks/archived/<task-slug>/`。
